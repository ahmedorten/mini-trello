# Support Guide

If you encounter issues or require help using this Enterprise AI Workspace Template, review the operational steps below.

---

## 1. Troubleshooting Resources
1.  **AI Integration Failures**: If an AI agent executes unauthorized tool operations, consult the [AI Agent Workspace Protocol](.ai/bootstrap/AI_PROTOCOL.md) and check capability limits in [.ai/capabilities/](.ai/capabilities/).
2.  **Maturity Stage Bounds**: If a developer tries to push code changes while the repo is locked in the `Planning` stage, check [Maturity Model](docs/maturity-model.md) rules.
3.  **Onboarding Roadblocks**: Check [.ai/bootstrap/START_HERE.md](.ai/bootstrap/START_HERE.md) and [Contributing Guide](docs/contributing.md).

---

## 2. Escalation Procedure
If a bug, relational schema clash, or conflict cannot be resolved using documentation:
- Log an issue inside the backlog using the Bug Report template.
- Assign the issue to the **Project Manager** or **Architect** for triage.
