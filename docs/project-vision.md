## 1. Product Core Values
1.  **Framework Swappability**: Build a system where backend and frontend engines are completely interchangeable.
2.  **Architectural Purity**: Minimize dependency on framework-specific magic. Code should be clean, highly decoupled, and follow SOLID design patterns.
3.  **Low Friction Learning Curve**: Keep requirements simple (e.g. core CRUD actions) to allow developers to focus on analyzing how different languages solve the same design goals.

---

## 2. Target Audience
- **Students & Junior Developers**: Seeking to transition from basic single-stack scripts to modular enterprise-style applications.
- **Experienced Engineers**: Evaluating alternative platforms (.NET Core, FastAPI, Vue, React) or demonstrating multi-stack designs.

---

## 3. Success Indicators
- **Interoperability**: The frontend client operates without modifications regardless of the active backend framework swap.
- **AI Readiness**: AI agents can immediately read context files and successfully implement new feature tasks.
