# Generic AI Review Checklist

## 1. Project Structure
- [ ] Folder structure is organized feature-modularly.
- [ ] Layer separation is respected.
- [ ] Configuration files sit in dedicated directories.

## 2. Documentation
- [ ] System requirements and scope boundaries exist.
- [ ] Architecture design and relational schemas exist.
- [ ] API routes and contract shapes are defined.
- [ ] Coding standards are clearly laid out.

## 3. AI Workspace Configuration
- [ ] AI Agent personas are configured.
- [ ] System context quick-starts exist.
- [ ] Reusable development prompts exist.
- [ ] Operational workflows are documented.

## 4. Project Management
- [ ] Epics and user story mappings exist.
- [ ] Sprints and backlog lists exist.
- [ ] Definition of Ready and Done are defined.

## 5. Backend Layer Compliance
- [ ] Proper routing, controllers, services, and repositories structure.
- [ ] Payload validation middleware in place.
- [ ] Custom error handling framework implemented.
- [ ] Stateless token authentication (JWT) active.
- [ ] Logging utilities active.

## 6. Frontend Layer Compliance
- [ ] Route guarding active.
- [ ] Global state management stores separated.
- [ ] Reusable UI components modularized.
- [ ] Input forms validated.

## 7. Code Quality & Security
- [ ] SOLID and DRY principles met.
- [ ] Clean variables and method naming casings.
- [ ] Parameterized database queries (SQLi defense).
- [ ] Access control checks on all restricted paths.
