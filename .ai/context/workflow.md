# AI Quick Start: Development Workflow Context

## 1. Purpose
This document provides a quick-start reference detailing the operational steps for task execution, PR auditing, and version tagging.

## 2. Summary
*   **Agile Flow**: Tickets traverse from Backlog → Todo → Doing → Review → Done queues inside `/tasks/`.
*   **Branching & Commits**: Branches use `feature/*` or `bugfix/*` naming, and commit messages conform to Conventional Commits.
*   **Releases**: Releases are tagged using Semantic Versioning (`vX.Y.Z`) on the stable main branch.
