## 1. Sprint Goal
The goal of Sprint 01 is to bootstrap the backend server environment, configure compiler tools and code linters, set up database ORM clients, and implement tested User Auth and Parent Resource CRUD modules.

---

## 2. Sprint Objectives
- Boot backend framework using typescript/strongly-typed compilation.
- Configure ORM schemas, database migrations, and local database services.
- Implement User registration, credentials login, and authentication middleware.
- Implement Parent Resource CRUD endpoints (create, list, detail fetch, edit, delete).
- Achieve >80% code test coverage on all developed endpoints.
